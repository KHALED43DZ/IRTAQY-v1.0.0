# إرتقِ | IRTAQY — الإصدار 1.0.0 (تجريبي)

مدرسة رقمية: سبورة تفاعلية + صوت وصورة، والأستاذ هو من يسمح للتلميذ بالمايك والكاميرا.
تعمل بالكامل من الهاتف أو الحاسوب، بدون خادم خاص وبدون حسابات، وتُستضاف مجاناً على GitHub Pages.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية وغرفة الحصة |
| `style.css` | التنسيق |
| `app.js` | منطق الأستاذ والتلميذ (الاتصال، الأذونات، الدردشة) |
| `board.js` | السبورة التفاعلية |
| `config.js` | الإعدادات ورقم الإصدار |
| `favicon.svg` | الأيقونة |

## النشر على GitHub Pages (من الهاتف)
1. فك ضغط الملف `IRTAQY-v1.0.0.zip` بتطبيق الملفات في هاتفك.
2. افتح github.com وسجل الدخول (يفضل تفعيل «موقع سطح المكتب» في المتصفح).
3. اضغط **New repository**، سمّه مثلاً `irtaqy`، واجعله **Public**، ثم **Create repository**.
4. اختر **uploading an existing file**، ثم **choose your files** وحدد كل الملفات بعد فك الضغط (7 ملفات).
5. اضغط **Commit changes**.
6. ادخل **Settings ← Pages**. في **Branch** اختر `main` والمجلد `/ (root)` ثم **Save**.
7. بعد دقيقة يظهر الرابط: `https://اسم-حسابك.github.io/irtaqy/`

لتحديث النسخة لاحقاً: ارفع الملفات الجديدة بنفس الطريقة (تستبدل القديمة).

## الاستعمال
**الأستاذ**
1. اكتب اسمك، اختر جودة الفيديو، واضغط «ابدأ الحصة» ثم اسمح بالكاميرا والمايك.
2. يظهر رمز من 6 خانات. اضغط «دعوة التلاميذ» لإرساله (واتساب مثلاً).
3. ارسم على السبورة، فيراها التلاميذ مباشرة. الأدوات: ألوان، سماكة، ممحاة، تراجع، مسح الكل.
4. تبويب «التلاميذ»: عند رفع اليد ✋ تظهر علامة. زر 🎤 يمنح أو يسحب المايك، و📷 الكاميرا، و✕ للإخراج.
5. اضغط «إنهاء» لإغلاق الحصة.

**التلميذ**
1. افتح رابط الدعوة (يملأ الرمز تلقائياً) أو أدخل الرمز، واكتب اسمك، ثم «انضم».
2. يرى السبورة ويسمع الأستاذ. مايكه وكاميرته مغلقان حتى يسمح الأستاذ.
3. «رفع اليد» لطلب الكلمة. إن لم يُسمع الصوت اضغط زر تفعيل الصوت على السبورة.

## حدود هذه النسخة
- حتى **8 تلاميذ** في الحصة (الاتصال مباشر بين الأجهزة، وجهاز الأستاذ يرسل الفيديو لكل تلميذ).
- لا توجد حسابات ولا اشتراكات ولا دفع بعد. الرمز يتغير في كل حصة.
- لا يوجد تسجيل للحصص، ولا تُحفظ السبورة بعد انتهاء الحصة.
- خوادم TURN العامة المجانية في `config.js` قد تكون بطيئة. إن لم يتصل بعض التلاميذ (خاصة على بعض شبكات الهاتف) فاستبدلها بحساب مجاني من metered.ca.
- الاتصال بين الأجهزة يمر عبر خادم الإشارة العام لمكتبة PeerJS (مجاني بلا ضمان).
